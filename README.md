# About
This is a mobile version for weather forecasting. It displays either today's weather or weather in the future. A setting option allows user to change location or change the unit for the temperature degree.

# Installation

This mobile app uses expo thus require expo tools. Install needed package via npm install or npx tunneling. 
Use npm start or expo start to start the mobile app and scan the qr code.

# Challenges

For some reason, I was unable to see any error code thus had a hard time locating and resolving bugs.
Since each weather forecast function is a self isolated component, I was able to just plug in the entire component and only had to worry about icons.
